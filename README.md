# One Line, One Laugh

My entry for the [One Line, One Laugh](https://make.fun/bounty/u-plucky-finch-20-one-line-one-laugh-0ffe66ea) bounty on make.fun: a single funny line of text, at most 200 characters, written to land its punchline inside the line itself — no setup, no picture, no explanation. The program in `main.ts` writes that line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `./output`), checks it is a single non-blank line of 1–200 characters, and reads the file back to confirm it matches exactly what was validated.

Run it with `node main.ts` (Node 22 or later, no dependencies).
